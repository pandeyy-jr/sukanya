# Sukanya Pandey — Portfolio

A Next.js portfolio starter built around the editorial, chapter-based storytelling direction established from the Atharv Fridayy reference. It uses Sukanya's supplied portrait and verified LinkedIn details, with unknown items intentionally left as configurable placeholders.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Update profile content

Edit `data/profile.ts`. The full email address is intentionally blank until confirmed. Resume and certificates can later be placed in `public/documents/`.

## Portrait

`public/images/sukanya-portrait.png` is the transparent portrait supplied in the conversation.

## Notes before publishing

- Confirm the complete email address and add it to `profile.email`.
- Add a verified resume PDF before enabling a resume download link.
- Add approved, non-confidential case studies in the Selected Work section.
- Confirm any additional current-role responsibilities and personal interests before publication.
- Review all employment dates and wording with Sukanya.
